## D. Decisions that Apply (with Why)
- **Why httpOnly cookies and never `localStorage`?** JavaScript cannot read httpOnly cookies, protecting tokens from XSS leakage (§3.17).
- **Why global guards with `@Public()` opt-out?** A new endpoint is protected by default, so forgetting a decorator cannot accidentally expose it (§3.17).
- **Why a `sessions` collection?** Logout must revoke the refresh token on the server and sessions must expire after 30 idle minutes (§3.9, §4.6.2).
- **Why an `ActiveBookingsCheck` port?** Accounts cannot import booking modules (which would create a dependency cycle), so a port inverting the dependency solves it (§3.3).
