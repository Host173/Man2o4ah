**`validation-exception.factory.ts`:** the `exceptionFactory` for the global `ValidationPipe`. It turns class-validator's `ValidationError[]` into

| Exception | Status | Code | Message | Details |
|---|---|---|---|---|
| `HttpException` whose response object has a string `code` | `getStatus()` | that code | its `message` | its `details`, if an array |
| other `HttpException` | `getStatus()` | by status: 400 `VALIDATION_FAILED`, 401 `NOT_AUTHENTICATED`, 403 `FORBIDDEN_ROLE`, 404 `NOT_FOUND`, 409 `CONFLICT`, any other 4xx `REQUEST_FAILED`, 5xx `INTERNAL_ERROR` | the response's `message` (an array joined with `; `), else `exception.message` | none |
| object with `code === 11000` (Mongo duplicate key) | 409 | `CONFLICT` | `Duplicate value` | one per key of `keyValue`: `{ field, message: 'already exists' }` (omit if no `keyValue`) |
| Mongoose `Error.ValidationError` | 400 | `VALIDATION_FAILED` | `Validation failed` | one per key of `errors`: `{ field: key, message: errors[key].message }` |
| Mongoose `Error.CastError` | 400 | `VALIDATION_FAILED` | `Invalid value` | `[{ field: path, message: 'invalid value' }]` |
| anything else | 500 | `INTERNAL_ERROR` | `Internal server error` | none |

`timestamp` is `now.toISOString()`. `path` is the argument.
